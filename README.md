# 🛒 E-Commerce Website

A basic e-commerce website developed using **Python and Django**, with HTML and CSS for the frontend.

This project allows users to browse products, create an account, log in, add products to their cart, and place orders. The administrator can manage products and view customer orders through the Django Admin panel.

## ✨ Features

- 🏠 Home Page
- 👤 User Registration
- 🔐 User Login
- 🚪 User Logout
- 🛍️ Product Browsing
- 🛒 Add Products to Cart
- 📦 Place Orders
- 📋 View Orders
- ⚙️ Django Admin Panel
- ➕ Admin can add and manage products
- 👀 Admin can view customer orders
- 🔒 Only registered/logged-in users can place orders

## 🛠️ Technologies Used

🔑 User Flow

User opens the website.
User can browse the available products.
User can register for an account.
Registered users can log in.
Users can add products to the cart.
Users can place an order.
The administrator can manage products and orders through Django Admin.

⚙️ Admin Features

The Django Admin panel allows the administrator to:

Add products
Update products
Delete products
View customer orders
Manage website data

🚀 How to Run the Project

1. Open the project folder
cd ecommerce-project
2. Install Django
pip install django
3. Run migrations
python manage.py migrate
4. Start the development server
python manage.py runserver
5. Open the website

Open the URL shown in the terminal, usually:

http://127.0.0.1:8000/
